# 本地文件管理器

基于 Electron 的**本地文件管理器**，跨平台，纯本地运行，**不上传任何文件**。

> 网络说明：程序运行时不访问网络、不上传任何文件内容；但**首次运行 `start.bat` 需要联网**下载 Electron 运行包（约 100MB，走 npmmirror 镜像），打包安装包时还需下载 electron-builder 的二进制。依赖装好后日常使用完全离线。

当前版本 **v0.2.1**。

> 本文按版本分段：**v0.1.0 一节是基础说明**（功能、运行、结构、平台差异），之后的每一节**只记录该版本相对上一版的改动**，不复述基础内容。发新版本时按 v0.2.0 的格式在末尾追加即可。

## v0.1.0（初始版本 · 基础说明）

### 界面与功能

三栏布局：左侧工作区、中间阅览区、右侧详情区。

- **多文库**：新建、切换、迁移、重新定位、移除登记（只删登记，不动磁盘文件）、重新扫描；文库注册表保存在应用数据目录的 `libraries.json`
- **文库结构**：文库 → 大类 → 组 → 文件；账本 `.library-index.json` 随文库目录一起存放，迁移后标签与封面不丢
- **组操作**：新建组（`YYYYMMDD_0001_组名`，同日序号接续）、添加文件（复制进组）、标签增删改、封面/预览图、重命名、迁移
- **检索**：文库内按文件名搜索、按类型筛选（图片/视频/文档/音频/压缩包/其他）、按标签筛选；结果平铺分页
- **阅览**：文库总览、文库首页、大类与组的卡片网格、图片/视频/音频/文本直接预览、全屏预览、用系统默认程序打开
- **导航**：面包屑、前进/后退、历史记录（可折叠、可清空）
- **详情与操作**：文件详情（大小、时间、类型等）；右键菜单重命名、迁移、删除（**移入系统回收站**）
- **兜底**：系统文件对话框不可用或被取消时，自动改用内置文件/文件夹选择器
- **安全**：`contextIsolation: true` + `nodeIntegration: false` + 渲染进程沙箱 + preload 白名单桥接；CSP 与窗口导航管控；主进程按真实路径（realpath）限制可访问范围，屏蔽系统目录与凭据目录；打开可执行文件需确认；删除不直接销毁文件。详见 v0.2.1 一节

> 补充：主进程还保留了一批早期遗留的底层文件操作接口（递归搜索、一键归类、批量重命名、复制/移动等），当前界面没有入口，它们属于保留能力而不是已上线的界面功能。

### 运行

**Windows（日常使用）**：依赖装好后双击 `start.bat`，它直接调用 `node_modules\electron\dist\electron.exe`，**不需要 Node.js**。

只有两种情况需要 Node.js 18+：

1. 首次安装依赖（要下载 Electron，约 100MB+，需联网）
2. 打包安装包（`打包成安装包.bat` 或 `npm run dist:win`）

`start.bat` 找不到 node 时会去常见安装位置再找一遍（`Program Files\nodejs`、`%LOCALAPPDATA%\Programs\nodejs`、nvm、fnm 等），都找不到才报错。

**其他平台**：

```bash
git clone https://github.com/My-Git-Lab/FileManager.git
cd FileManager
npm install
npm start
```

### 打包

| 目标平台    | 命令                                | 产物                        |
| ------- | --------------------------------- | ------------------------- |
| Windows | `打包成安装包.bat` 或 `npm run dist:win` | `release/*.exe`（NSIS 安装包） |
| Linux   | `npm run dist:linux`              | `release/*.AppImage`      |
| macOS   | `npm run dist:mac`                | `release/*.dmg`           |

- Windows 安装包建议在 Windows 电脑上打包（或在其他平台装 Wine）
- 打包产物在 `release/`，已被 `.gitignore` 排除
- 打包后是独立应用，无需 Node.js
- Electron 不支持手机端；若需手机访问文件，需另做局域网 Web 应用

### 文件结构

| 文件                                          | 职责                                  |
| ------------------------------------------- | ----------------------------------- |
| `main.js`                                   | 主进程：文件系统操作、文库账本与注册表、全部 IPC 接口       |
| `preload.js`                                | 安全桥接：暴露 `window.api`                |
| `index.html` / `styles.css` / `renderer.js` | 三栏界面与交互逻辑                           |
| `start.bat`                                 | Windows 一键启动（依赖装好后无需 Node.js）       |
| `打包成安装包.bat`                                | Windows 一键打包成 .exe 安装包              |
| `package.json` / `package-lock.json`        | 版本与依赖，**版本号唯一来源是 `package.json`**   |
| `.gitattributes`                            | 强制 `*.bat` 保持 CRLF + GBK，不要转成 UTF-8 |

> 仓库里**没有** `文件库/` 目录：示例文库属于本地数据，已被 `.gitignore` 排除。首次使用请在界面里「新建」一个文库，数据存在你指定的位置，不随程序提交。

### Windows 平台差异（源自 Linux 开发环境，已修复，后续改动请保持）

| 项目              | Linux                    | Windows                                   |
| --------------- | ------------------------ | ----------------------------------------- |
| 允许访问的根目录        | 用户目录 + `/media`、`/mnt` 等 | 用户目录 + 各存在的盘符根目录（C:\、D:\…）                |
| 文件名             | `<>:"/\|?*` 都合法          | 非法；另有 CON/PRN/AUX/NUL/COM1~~9/LPT1~~9 保留名 |
| 文件名大小写          | 敏感                       | 不敏感（只改大小写不算「同名」）                          |
| 跨盘/跨分区移动        | `rename` 可能失败            | 同上，需退回「复制后删除」                             |
| 用户目录（桌面/文档/下载…） | `~/Desktop` 等            | 可能被 OneDrive 重定向，要用 `app.getPath()`       |

## v0.2.0

相对 v0.1.0 的改动：

**项目整理**

- **版本号统一为 `0.2.0`**：`package.json`、`package-lock.json` 顶层两处（原分别为 `0.1.0`、`1.7.2`）；清除源码注释里遗留的内部版本号（v1.1 ~ v1.7.1），约定版本号唯一来源是 `package.json`，版本历史统一由本文维护
- **修正接口参数矛盾**：`fs:organize` 主进程原本按 `{ dirPath }` 解构、桥接却传字符串，改为一致
- **精简 preload 暴露面**：移除当前界面未接入的旧版桥接，最终暴露 23 个方法与 `renderer.js` 调用一一对应；主进程对应 handler 全部保留，后续接入只需补回桥接行
- **文档校正**：README 改为按版本分段；功能描述按实际三栏文库界面重写（原文混入了无界面入口的旧版功能）；文件结构表移除并不存在的 `文件库/`；`package.json` 的 `description` 改为与实际形态一致

**新增「批量添加」**

- 左侧「快捷操作」新增按钮，点击弹出**单页表单**，5 项依次排列：① 待添加的文件（可反复选择多个文件 / 整个文件夹，文件夹递归展开、跳过隐藏文件、平铺放入目标组）② 目标位置（**文库 / 大类 / 组**均可：选前两者自动新建组，可填组名、可新建大类；选组则直接加入）③ 作者 ④ 标签（可多个）⑤ 来源
- 一次最多 5000 个文件；为避免重复复制，位于目标文库内部的源文件会被跳过
- 通用弹窗为此扩展了宽屏模式、可关闭「回车即确定」、可禁止点遮罩关闭；表单状态独立于 DOM，系统对话框不可用时改用内置选择器也不会丢失已填内容

**详情与维护信息：作者 / 标签 / 来源**

- **只保留 3 类维护信息**。除文件系统自带的统计信息（名称、大小、数量、类型 / 后缀、时间等）外，额外记录的信息只有「作者」「标签」「来源」；上一开发版中的「添加时间」不再记录
- **账本模型统一**：`.library-index.json` 新增 `meta` 字段，按「相对文库根目录的路径」索引——`''`=文库、`大类`=大类、`大类/组`=组、`大类/组/文件`=文件。作者与来源为字符串数组（可多值），标签为带颜色的对象数组。每个扫描出的对象都带 `rel`，界面据此定位
- **文件层级只存标签**，不记录作者与来源；批量添加提交的 3 类信息统一保存到**目标组**（已有值合并去重，往同一组反复添加不会互相覆盖），组内文件靠继承显示
- **继承是单向向下的合并并列**：显示时把本级与各级祖先的非空值合并——标签取并集，作者 / 来源多值并列，并标注来源层级；本级填了值不会覆盖祖先值。例：文库作者 + 组作者会同时出现在组内文件可继承的链上；组的标签也是组内文件的标签。账本只存各级「自己填的值」，改上级后下级自动跟着变
- **右侧详情按层级显示其全部信息**：位于文库 / 大类 / 组时，固定显示统计信息 + 3 类维护信息，未填写显示「空」；文件详情只显示标签，没有任何标签时整块不显示，也不出现作者 / 来源行
- **统一「编辑信息」入口**：各层级详情都有编辑按钮（文件层只有「编辑标签」），弹窗里只改本级自己填的值；作者 / 来源 / 标签都支持用「、」一次填多个。新增 `lib:setMeta` IPC，preload 桥接 `libSetMeta` 取代原 `libSetTags`
- **按标签检索增加「搜索层级」**：左侧「按标签」模式下出现 文库 / 大类 / 组 / 文件 四个复选框，可多选、选择会持久化；命中口径为「含继承后的有效标签」，结果按所选层级给出带层级角标的混合卡片，单击看详情、双击进入。检索范围沿用「当前文库」，不跨库
- **旧数据自动迁移**：首次扫描会把旧版 `categories[].groups[].tags` 与按文件存的 `fileMeta` 合并到组级 `meta`（文件级作者 / 来源上提到所属组），随后删除 `fileMeta` 并标记 `metaVersion`。文件 / 组 / 大类改名、跨文库迁移都会同步 `meta` 的键；文库整体迁移或重新定位后相对路径不变，信息不丢
- **信息存在账本里，不修改原始文件本身**；组「预览图」保留为卡片缩略图功能，不再作为维护信息在详情中列出

**顺带修复**

- `lib:rename` 改文库名时判断的是 `library`、界面实际传的是 `lib`，导致注册表与账本一直没同步
- `fs:detail` 在 Windows 上不再显示无意义的 `undefined / undefined` 与权限数字
- `styles.css` 里 `--text-weak` 的自引用改成实际颜色值
- 「新建组」逻辑抽成共用函数供批量添加复用

> 上述改动均为本地工作区修改，尚未提交 / 推送；底层文件操作能力未删除。

## v0.2.1（安全与隐私加固）

相对 v0.2.0 的改动，全部是安全 / 隐私 / 健壮性修复，无新增功能。

**运行防护**

- **移除 `--no-sandbox`**：`start.bat` 之前带这个参数，等于关掉了 Electron 的渲染进程沙箱。实测去掉后程序照常启动，现已恢复默认沙箱；`webPreferences` 显式声明 `sandbox: true` / `webSecurity: true`
- **窗口锁死在本地页面**：`createWindow()` 新增 `will-navigate`（只放行本应用 `index.html`）、`setWindowOpenHandler`（一律拒绝新窗口）、`setPermissionRequestHandler` / `setPermissionCheckHandler`（拒绝摄像头、麦克风、定位等全部权限）
- **CSP 收紧**：补 `object-src 'none'`、`base-uri 'none'`、`form-action 'none'`、`frame-src 'none'`、`connect-src 'none'`
- **打开可执行文件需确认**：`fs:open` 遇到 `.exe` / `.msi` / `.bat` / `.ps1` / `.lnk` 等扩展名会先弹确认框，避免渲染层被注入后静默拉起任意程序
- **路径白名单加固**：`isAllowed()` 改用 `realpath` 解析真实路径（堵住符号链接 / Windows junction 绕过），并屏蔽系统目录、浏览器凭据库、`~/.ssh` 等敏感位置。可选 `FM_STRICT_ROOTS=1` 开启严格模式，只放行用户主目录、程序目录与已登记文库；额外目录可用 `FM_WRITE_ROOTS` 追加（用 `path.delimiter` 分隔）。若确需管理被屏蔽的系统 / 凭据目录，启动时设 `FM_ALLOW_SENSITIVE=1` 可自行放开（环境变量只能由启动进程设置，渲染层无法修改）

**注入与隐私**

- **标签颜色白名单**：`.library-index.json` 里的 `tags[].color` 曾被原样插进 HTML `style` 属性，恶意账本可注入 `<a href>` 等标签。现在主进程落盘与渲染层双重过滤，只接受 `#RGB` / `#RGBA` / `#RRGGBB` / `#RRGGBBAA`
- **`escapeHtml()` 补单引号转义**（`'` → `&#39;`），堵住单引号属性插值这个易碎点
- **账本不再存绝对路径**：`.library-index.json` 落盘时只写相对路径（统一 `/`，标记 `pathVersion: 2`，不再写 `root`），读取时按当前文库位置还原。文库文件夹被打包分享 / 放进网盘时，不会泄露本机用户名与完整目录结构；旧版账本（含 Linux 绝对路径）自动迁移，账本里埋 `../` 试图指向文库外会被拒绝
- **文库预览图路径修正**：`<img src>` 统一走 `fileUrl()`，此前两处直接塞绝对路径导致封面显示不出来

**健壮性**

- `fs:trash` 兜底不再把文件静默挪到 `~/.Trash-filemanager` 后仍报告「已移入回收站」：改为明确回报实际去向，跨盘改用复制 + 删除
- `fs:transfer` / `lib:migrate` / `lib:move` 跨盘移动时，删源前先校验副本的文件数与字节数一致，不一致就保留源文件并报错
- `lib:rename` 补上 `nameError()`（Windows 非法字符、结尾空格 / 句点、保留设备名）
- `fs:detail` 在 Windows 上不再无条件读取 `/etc/passwd`、`/etc/group`

> 说明：`%APPDATA%/local-file-manager/libraries.json` 与 localStorage 仍存本机绝对路径，它们是本机运行配置、不随文库文件夹分享，故未改动。

## v0.3.0 及以后

发新版本时，在上方按时间顺序追加一节，**只写该版本相对上一版的改动**（新增 / 修复 / 移除 / 配置变更），不要复述 v0.1.0 的基础说明。

固定动作：改 `package.json` 的 `version` → 同步 `package-lock.json` 顶层两处 → 在本文追加版本节 → `git commit` → 打 tag → 打包 → 发布 Release。版本格式为主版本.次版本.修订号（semver），`electron-builder` 会用它命名安装包。
